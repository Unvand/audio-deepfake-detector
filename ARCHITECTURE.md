# Архитектура проекта

## Общая идея

Проект разделён на независимую обработку аудио, desktop-интерфейс и
исследовательский notebook. GUI не содержит алгоритмов классификации и не
пытается самостоятельно определять REAL/FAKE.

## Структура

```text
audio_deepfake_detector/
├── app/
│   ├── application.py       # создание QApplication и единый запуск
│   ├── main_window.py       # навигация, состояние GUI, жизненный цикл QThread
│   ├── workers.py           # фоновая оркестрация анализа
│   └── widgets/             # независимые визуальные компоненты
├── src/
│   ├── preprocessing.py     # загрузка, mono, resampling, окна
│   ├── audio_analysis.py    # F0, MFCC и спектральные признаки без Qt
│   └── inference.py         # контракт будущей CNN
├── notebooks/               # исследование протокола ASVspoof 5
├── models/                  # локальные веса; в Git не добавляются
└── results/                 # локальные результаты; в Git не добавляются
```

Корневой `main.py` — рекомендуемая точка запуска. Вложенный
`audio_deepfake_detector/main.py` оставлен как совместимая точка запуска из
каталога проекта. Оба используют одну функцию `run_application`, поэтому логика
не дублируется.

## Поток данных

1. Пользователь выбирает WAV, FLAC, MP3 или OGG в `MainWindow`.
2. `read_audio_metadata` читает доступную техническую информацию. Недоступный
   bitrate не считается фатальной ошибкой.
3. После нажатия «Начать анализ» создаются отдельные `QThread` и
   `AnalysisWorker`.
4. Worker загружает аудио через `preprocessing.load_audio`, переводит stereo в
   mono и выполняет resampling до 16 кГц.
5. Чистые функции `audio_analysis` независимо рассчитывают F0, MFCC и
   спектральные характеристики. Ошибка одного признака сохраняется локально и
   не отменяет остальные расчёты.
6. Worker передаёт словарь результата в главный поток сигналом Qt.
7. Виджеты обновляют waveform, обычную спектрограмму и числовые показатели.
8. `inference.py` сообщает, что CNN не загружена; GUI показывает
   `МОДЕЛЬ НЕ ЗАГРУЖЕНА` без фиктивного результата.

## Будущее подключение CNN

Точка расширения — класс `AudioDeepfakeInference` в `src/inference.py`.
Позднее он сможет:

- загрузить выбранные веса из `models/`;
- применить согласованную с обучением предобработку;
- вернуть `InferenceResult(verdict, confidence)`.

Контракт результата уже поддерживается `NeuralAnalysisWidget` и
`ResultWidget`, поэтому переписывать GUI не потребуется. Выбор архитектуры CNN,
параметров Mel-спектрограммы и обучение находятся за пределами текущего этапа.

## Независимые компоненты

- `preprocessing.py` не зависит от Qt и интерфейса.
- `audio_analysis.py` не зависит от Qt и не классифицирует аудио.
- виджеты отвечают только за отображение.
- `AnalysisWorker` связывает вычисления с сигналами Qt.
- notebook не импортируется desktop-приложением.
- отмена анализа кооперативная: worker завершает текущий вычислительный этап,
  проверяет запрос отмены и корректно останавливает `QThread`.
